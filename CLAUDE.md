# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Objetivo

O site existe para facilitar a montagem de um roteiro de viagem: a pessoa deve conseguir montar o roteiro de forma prática e rápida, sem se preocupar em estar deixando de fazer algo legal ou de conhecer um lugar que ela nem sabia que existia. Por isso, cada país cobre o que é reconhecido na região em cada categoria (pontos turísticos, comidas, paisagens, experiências, lojas, hospedagem, rotas e transporte), e não apenas o óbvio.

## Convenções do conteúdo

- Os lugares do site (em `dados.js`, nos 6 países; os "51 lugares" que aparecem são só os do Brasil) foram definidos por IA, sem verificação. Nomes, descrições, coordenadas, faixas de preço, durações e distâncias podem conter erros e devem ser conferidos antes de serem tratados como confiáveis.
- Preços e tempos de deslocamento são aproximados por design; o site avisa para confirmar antes de viajar.
